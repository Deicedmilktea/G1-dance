# Oldschool 实验日志

本文件记录 unitree G1 复现蔡徐坤《Old School》舞蹈片段（11.94 秒、359 帧 @ 30 fps → 597 帧 @ 50 Hz）的完整实验脉络与结果（EXP-010 至 EXP-020），涵盖失败记录与退化保护线。时间统一使用 Asia/Shanghai（UTC+8），路径均相对于仓库根目录；本地详细产出保存于 `outputs/`。

## 共同输入与起点（2026-11-11）

- **起点权重**：南大 [SuperMimic-Repro-Sim2Real v1.0](https://github.com/NJU-R-L-Group-Embodied-Lab/SuperMimic-Repro-Sim2Real/releases/tag/v1.0) 发布权重 `e13i_0291000`（`models/supermimic/e13i_0291000/ckpt_e13i_0291000.pt`）。
- **原始 G1 参考**：使用 GVHMR 恢复与 GMR 重定向后的完整 359 帧全片动作，转换至 50 Hz 的 597 帧 NPZ（`outputs/motions/oldschool_full_v1.npz`）。
- **FT1 全片适配**：从南大发布权重在原始全片参考上微调 600 步（配置见 `configs/oldschool/ft1.json`）。固定起点下南大原版与 FT1 均无重置跑完 11.94 秒，片尾朝向误差从 `33.2°` 降至 `10.8°`，全片关节角 RMSE 从 `7.50°` 升至 `9.35°`；但两者均未能双脚同时腾空，原参考在空中的质心加速度（约 `-6.15 m/s²`）与仿真重力（`-9.81 m/s²`）不符。后续实验围绕「如何在不破坏全片舞步的前提下完成真实双脚离地跳跃」展开。

仅五个留出起点：冻结、强化、模仿的较低脚峰值均值 0.26 / 3.68 / 33.15 cm；稳定跳跃分别 0/5、5/5、5/5；末帧朝向均值 32.80° / 20.24° / 18.05°。模仿版这五次的较低脚峰值在 28.75–35.70 cm。两版逐起点都改善片尾平均及末帧朝向、降低骨盆位置误差，但全片关节误差都有增加。强化学习提高右膝与开脚间距的保真度，左膝明显退化且没有复现高跳；模仿左膝和双脚高度更近，两版各有 4/6 次达到开脚时机的间距阈值。两版均早于原始重定向约 7.00 秒的近地几何时刻。

两条训练采用不同的数据和计算预算，结果支持在本舞段上相对南大基线的受控比较；不代表算法普遍优劣或实机性能。逐组 JSON、名义视频和慢放已保存在 `outputs/evaluation/oldschool_nju_direct_v1/shared/`；公开说明见 [Oldschool 南大直训](nju_direct_training.md)。

## EXP-019｜2026-11-13｜已有跳跃路线的离线原因分析

触发：用户观察到南大直训 RL 跳高不足、模仿版身姿不协调，而 FT1 后续 RL 的综合观感较好，要求先分析项目。本轮核对 EXP-017/018 的训练谱系、奖励、采样、教师与物理轨迹，没有新训练、物理积分或权重、参考变更。

重新核对两轮各六个初态的模型、初始位姿/速度和参考帧索引；全身误差统一对原始 G1 参考离线计算。EXP-017 实际 actor 起点为 EXP-013 的成功小跳策略，包含 FT1 全片适配和小跳示范学习，目标另改为约 22 cm 的高跳参考；不能将两轮差异仅归为 baseline。两轮还改变了辅助奖励、重置规则、动作噪声和训练种子。

| 六组均值 | EXP-017 分阶段 RL | EXP-018 南大直训 RL | EXP-018 南大直训模仿 |

躯干取 `torso_link`，误差比较实际与同帧原始参考的身体坐标竖直方向；跳跃窗 6.12–7.12 秒、恢复窗 6.52–7.20 秒。质心按整机刚体质量加权，脚高同时受收腿和身体构型影响。五个留出初态的质心上升为 10.04 / 5.35 / 5.09 cm，主要区别不依赖展示起点。

南大直训模仿的 21 条合格教师示范，其跳跃窗躯干倾斜误差均值为 13.15°、腰关节误差 9.05°，与学生 12.74°、8.90° 接近，确认身姿偏差在示范中已存在。教师筛选主要约束脚、膝、踝距、骨盆落稳和朝向；监督拟合的目标是电机指令，不能自行修正教师的全身协调。展示起点的学生相对教师在跳跃窗平均还有约 9.4 cm 骨盆位置差，闭环偏离同样存在。

南大直训 RL 在展示起点约 6.44 秒已左脚着地、右脚仍离地约 31.4 cm，双膝约 27.4°/128.0°；其低脚高包含收腿不对称与提前触地。原始参考空中质心加速度复算约 −6.15 m/s²，与无外力腾空的 −9.81 m/s² 不一致。分阶段的初始跳跃能力、较一致的参考和显式质心目标共同构成合理解释，各项贡献尚未分离。

保留分阶段 RL 为值得继续研究的综合候选，同时保留其既有逐初态朝向/位置退化及原模型更低的部分全片误差。后续建议是在统一参考、奖励和采样后对比发布 actor、FT1 actor、成功小跳 actor，并先改善教师的躯干与恢复约束；本轮没有执行新试验。复算脚本、逐组数据、分析笔记及图表保存在忽略目录 `outputs/diagnostics/oldschool_route_audit_v1/`。开源文档结构留待后续讨论。
