# Oldschool：与南大发布策略的全片对照

在同一段 11.94 秒的 Oldschool 舞蹈上，微调策略能双脚离地并稳定落地，片尾朝向更准，但全片关节角误差更大。使用未经小跳修改的原始参考时，这个结论仍成立；原参考的高跳尚未复现。

## 比较对象与条件

- **南大原版**：南京大学 R&L Group Embodied Lab 的 SuperMimic-Repro-Sim2Real [v1.0 发布版](https://github.com/NJU-R-L-Group-Embodied-Lab/SuperMimic-Repro-Sim2Real/releases/tag/v1.0)权重 `e13i_0291000`。这是项目续训的起点。实验前校验发布归档 SHA-256，并确认从归档提取的检查点和评测文件一致。该版本是在南大基础模型上加入舞蹈数据后训练得到的。
- **本项目策略**：以同一发布权重在 Oldschool 原始全片上续训 600 个向量环境步得到 FT1，再从 FT1 监督微调动作解码器。示范来自能跳起并站稳的控制器，训练目标是它实际执行的关节指令。评测时只加载微调后的权重。见[实验日志 EXP-011、EXP-013](experiments.md)。
- **两份参考分别配对**：主实验使用 GVHMR 恢复人体动作并由 GMR 转成 G1 后的原始参考；辅助实验使用只在 6.00–6.96 秒修改跳跃的小跳参考。每次两版 policy 读同一份参考，从相同的初始姿态和速度运行。两份参考的目标朝向逐帧相同。
- **每份参考六个初态**：从片头开始，固定起点 0，加五个使用上游重置扰动的起点 101、102、104、113、127。两份参考之间对应起点也相同。单环境、相同 G1 模型、50 Hz 控制、200 Hz 物理步、重力 −9.81 m/s²。评测冻结权重，无动作补偿、外力、运行期动作噪声或中途重置，保留首次终止。

## 结果

数值取六次配对的均值，各误差对该列所用参考计算。离地峰值先取每帧两只脚底中较低的高度，再取跳跃窗口内的最大值。

原始参考的较低脚离地峰值是 **37.76 cm**，本项目在六组起点实测 **4.08–6.04 cm**，首次触地 **6.440–6.465 秒**。原始参考在 **7.00 秒**才有第一只脚回到距地面 1 cm 内；这个参考时刻由几何位置计算。小跳参考的峰值是 **12.68 cm**，本项目实测 **10.82–11.91 cm**，首次触地 **6.530–6.550 秒**。两种参考下，本项目均为左脚先触地，落地后均达到恢复支撑的判据。

两种参考下，本项目的末帧朝向误差逐起点均减小，全片关节角误差逐起点均增大。末帧改善也不代表片尾全程改善：原始参考的起点 104 在最后一帧为 22.87° → 20.80°，但 10 秒至片尾的平均误差为 17.39° → 22.16°。

腾空判据是在 6.12–7.12 秒内连续至少两条 50 Hz 状态的双脚底净空大于 2 cm，并用 200 Hz 保存位姿复算离地和首次接触。落地恢复判据是首次接触后 0.30 秒内，至少 9 条控制采样有脚底距地不超过 1 cm，骨盆高度不低于 0.55 m、倾斜不超过 25°，且无非脚部触地。双膝和踝距分别用 6.32–6.56 秒、6.36–6.64 秒；踝距沿骨盆朝向坐标的横向计算。跳跃之外的误差排除 6.00–7.12 秒。

本结果支持这段舞的仿真起跳、落地与朝向改善。两版权重之间还包括全片续训和示范微调两个阶段，因此本对照不能分离两阶段各自对片尾的贡献。测试只覆盖一个舞蹈和一份训练权重；其他舞蹈、其他训练种子和实机尚未验证。

## 复跑

以下命令从已配置的仓库根目录执行，需要先准备两份动作和两个检查点。本报告不随 Git 分发原视频、生成的参考动作、本地训练权重或仿真录像。南大权重下载方式见[模型准备](setup.md)；本项目动作与权重的实验来源见[实验日志](experiments.md)。仅有本仓库代码无法复现这些具体数值，仍需获得相同输入或按同一流程生成。

| 评测输入 | SHA-256 |
|---|---|
| 南大 `ckpt_e13i_0291000.pt` | `3ff632f09b07e6dd26d1cbf46ba81dfc5f03368b26ef0af0ec217671cf7b2525` |
| 本项目 `ckpt_actor.pt` | `6ddf23280ed20250a159c834469f781692657e27aecdaaea698287a050251549` |
| 原始 `oldschool_full_v1.npz` | `6f4f0e218a506b63452ebf9542e27a39bb30d13369cbcd528a4344ff1e80e2d7` |
| 小跳 `oldschool_local_low_hop.npz` | `7be1584eb81cc375b33c33ae8bf824086faafbc12ae0d00c67685c2a787a1041` |

```bash
out=outputs/evaluation/oldschool_released_policy_pair_repro
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 ./envs/run.sh training tools/record_policy_pair.py \
  --baseline models/supermimic/e13i_0291000/ckpt_e13i_0291000.pt \
  --candidate outputs/training/oldschool_jump_imitation_v1/ckpt_actor.pt \
  --motions outputs/motions/oldschool_full_v1.npz \
            outputs/evaluation/oldschool_jump_audit_v1/oldschool_local_low_hop.npz \
  --seeds 0 101 102 104 113 127 --output "$out"
./envs/run.sh training tools/summarize_oldschool_policy_pair.py "$out"

for motion in oldschool_full_v1 oldschool_local_low_hop; do
  ./envs/run.sh training tools/render_policy_physics.py \
    --run "$out/$motion/seed0/candidate" --baseline-run "$out/$motion/seed0/baseline" \
    --baseline-label 'NJU RELEASE e13i_0291000' --policy-label 'OURS | NO COMPENSATION' \
    --show-heading-error --camera-distance 3.5
done
```

`comparison.json` 保存逐组结果。评测工具验证输入文件前后的哈希，逐组对齐初始姿态、速度、参考帧和仿真模型。渲染读取已保存的轨迹，左栏是当轮使用的参考，中栏是南大原版，右栏是本项目策略。
