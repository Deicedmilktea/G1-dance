# Oldschool：从南大发布权重直训

在一段 11.94 秒舞蹈上，比较冻结南大原版、从原版直训的强化学习策略、从原版直训的监督模仿策略。这个比较回答两个具体训练方案各自比公开起点多带来什么。

## 统一输入

- 起点是南京大学 R&L Group Embodied Lab 的 [SuperMimic-Repro-Sim2Real v1.0 发布权重](https://github.com/NJU-R-L-Group-Embodied-Lab/SuperMimic-Repro-Sim2Real/releases/tag/v1.0) `e13i_0291000`，检查点 SHA-256：`3ff632f09b07e6dd26d1cbf46ba81dfc5f03368b26ef0af0ec217671cf7b2525`。两条路线均从同一发布 actor 开始。
- 训练、评测及数值打分都使用原始 GVHMR→GMR→G1 Oldschool 参考 `outputs/motions/oldschool_full_v1.npz`，SHA-256：`6f4f0e218a506b63452ebf9542e27a39bb30d13369cbcd528a4344ff1e80e2d7`。旧小跳与高跳参考、本地微调权重和既有轨迹不进入这轮训练。
- 评测单环境，50 Hz 控制和 200 Hz 物理步。三组逐一起点对齐初始位姿、速度、参考帧、模型和环境；无推力、无动作补偿、无中途重置。固定起点 0 用于开发与演示；201、202、204、213、227 在选点前留出。

## 两条训练路线

强化学习继承南大发布的世界模型及其优化器、critic 网络和 actor 网络。actor 与 critic 的优化器重新初始化，回放和采样器重新开始。只更新 actor 解码器后三层，保留原有参考追踪目标，在起跳段增加蹬地速度、双脚净空、收腿、开脚和落地的分段奖励，辅以跳跃外动作约束与小权重的片尾朝向奖励。辅助净空奖励饱和于 22 cm；原参考文件、常规姿态追踪目标和推理输入均未换成 22 cm 的参考。

监督模仿在同一原始参考和南大 actor 上，用局部电机目标偏移搜索教师。历史偏移参数仅用作搜索提案；示范和锚定动作全部新录。合格教师用 200 Hz 触地状态检查双脚腾空、落地和整个舞段。最终用 14 个起点训练、6 个起点离线验证，固定 1,200 步。候选在名义及留出回放之前按离线结果确定。运行时只加载学生权重。

## 指标

跳跃窗 6.12–7.12 秒内，在连续至少两个 50 Hz 状态中两只脚底都高于地面 2 cm 计为持续双脚腾空。由保存的 200 Hz 位姿重算首次物理触地；随后 0.30 秒内需保住支撑、骨盆高于 0.55 m、最大倾斜不超过 25°、无非脚部接触，并跑完舞段，才计为稳定落地。以两只脚中较低一只的离地高度作为跳高。左右膝和横向踝距的均方根误差分别在 6.32–6.56 秒、6.36–6.64 秒测量。开脚时机按参考横向踝距阈值定义，未达到阈值记为缺失。

原始参考的较低脚峰值约 37.8 cm，首次回到距地 1 cm 的参考时刻约 7.00 秒。后者是运动学几何读数；两脚都离地时，原参考的整机质心轨迹也不完全符合重力。因此同时报告实际触地、稳定性与量化跟踪误差，真人视频仅作视觉对照。

两种直训版都在五个留出起点重复了稳定跳跃。监督模仿在这次训练配置下更接近原跳跃的双脚高度和左膝收腿，强化学习对右膝和开脚幅度的误差更小。两版各有 4/6 次达到开脚间距阈值；仅在这些样本上，强化学习和监督模仿平均分别晚 70 ms、55 ms。两版权重在每个起点都降低了片尾段和末帧朝向误差，但在每个起点都增加了全片关节角误差；都未达到原动作逐帧复现。

强化学习正式用 2048 个环境、1024 批量，900 个向量步和 334 次更新，耗时约 385 秒，整卡峰值 5752 MiB。模仿先做教师搜索与重录，再拟合学生；教师筛选的计算量和强化训练的更新次数不同，因此两条路线不作为同等计算预算的算法比较。只评测这一个舞蹈、一份训练种子和仿真，不外推至其他舞蹈或实机。

## 本地复跑

如果已经有匹配输入、检查点和本轮产物，可在项目根目录使用下列命令复核逐起点结果。脚本、配置和清单保存在同一实验目录，细节见 [EXP-018](experiments.md#exp-0182026-11-13南大发布权重在原始参考上的直接续训)。这些目录中的原片、轨迹、教师示范和模型权重没有随 Git 分发。公开文档中的输入校验值便于核验相同资产；仅凭公开文档不能重现训练权重。

```bash
work=outputs/evaluation/oldschool_nju_direct_v1/shared
rl=outputs/training/oldschool_nju_direct_rl_v1_train/ckpt_latest.pt
imitation=outputs/training/oldschool_nju_direct_imitation_v1/ckpt_actor.pt
./envs/run.sh training "$work/compare_runs.py" \
  --arm rl "$work/evaluation/rl_probe" "$rl" \
  --arm imitation "$work/evaluation/imitation_probe" "$imitation" \
  --output "$work/recheck.json"
```
