# EXP-020：同一份参考，两份策略

把南大 [v1.0 发布权重](https://github.com/NJU-R-L-Group-Embodied-Lab/SuperMimic-Repro-Sim2Real/releases/tag/v1.0) `e13i_0291000` 与成片使用的 EXP-017 高跳 RL 权重放进同一个 G1 仿真。两组各从片头跑 11.94 秒，用相同的初始位姿和速度、参考帧、动作接口和仿真设置。策略在评测中保持冻结，关闭动作补偿、外推力和中途重置。

| 输入给两份策略的参考 | 来源 | 原对照复用的轨迹 |
| --- | --- | --- |
| 原始 G1 参考 | Oldschool 原片经 GVHMR 恢复、GMR 重定向 | EXP-018 南大发布策略 |
| 修订高跳参考 | 同一舞段的跳跃附近目标经过调整；成片右侧用这份参考 | EXP-017 成片 RL |

每种参考都跑展示初态 `0` 和五个留出初态 `201、202、204、213、227`。展示使用固定初态，留出初态使用相同的上游重置扰动；主表取五个留出初态。评测比较的是这段舞上的两份固定策略。

## 从逐初态数据重算表格

在项目根目录执行：

```bash
python3 tools/evaluate_oldschool_exp020.py report
python3 tools/evaluate_oldschool_exp020.py report --include-display
```

[逐初态数据](../results/oldschool/exp020.json)保留两种参考下的 24 条轨迹指标。每条记录带初态、完成和落地判定，以及净空、跟踪误差和落地指标。两份策略都完成舞段的配对进入误差均值；没有落地测量的值记为 `null`。原始参考下，两版都 5/5 完成舞段，双脚腾空并落稳为 **0/5 → 5/5**。修订高跳参考下也是 **0/5 → 5/5**，脚部竖直轨迹 RMSE 为 **29.39 → 12.51 cm**，全片关节角 RMSE 为 **7.56° → 9.21°**。

## 指标怎么测

- **双脚腾空并稳定落地：** 在仿真时间 6.12–7.12 秒内，双脚净空连续至少两个 50 Hz 采样都超过 2 cm。用 200 Hz 状态和碰撞几何复核无接触段及落地。落地后 0.3 秒内，至少有 9 个控制采样的较低脚底净空不超过 1 cm，骨盆倾角不超过 25°、高度不低于 0.55 m；同时须完成舞段且无非脚部触地。
- **较低脚底峰值净空：** 每个控制采样取两只脚中较低一侧的足底净空，再取跳跃窗内的最大值，单位 cm。
- **跳跃动作误差：** 双脚竖直轨迹和左右膝角取 6.32–6.56 秒，双踝横向间距取 6.36–6.64 秒。两种参考条件下都按记录的帧索引对比原始 G1 动作。
- **全片跟踪误差：** 关节角、骨盆位置和朝向对比当轮两份策略共用的输入参考。片尾平均绝对朝向误差从第 10 秒算起，另报末帧误差。

## 从权重和参考复跑

用能运行项目 [SuperMimic / mjlab 环境](../envs/README.md)的 CUDA 机器。[上游版本](../configs/upstream_sources.json)记录源码和依赖；整理本入口时使用 Python 3.12、MuJoCo 3.16.0、mjlab 1.6.0 和 PyTorch 2.14.1+cu126。

从项目目录运行，下例把待准备的输入放在 Git 忽略的 `local/oldschool/` 下，路径可以替换：

```bash
./envs/run.sh training tools/evaluate_oldschool_exp020.py run \
  --baseline local/oldschool/nju.pt \
  --candidate local/oldschool/final_rl.pt \
  --original local/oldschool/original.npz \
  --high local/oldschool/high_hop.npz \
  --output outputs/evaluation/exp020_replay
```

两份权重和两份参考是单独准备的输入，脚本按[固定 SHA-256](../configs/oldschool/exp020.json)核对。输出目录须是新目录。默认运行两个参考条件 × 六个初态 × 两份策略；加 `--seeds 201` 可先检查一个留出初态。入口重新录制所选的轨迹，核对两策略的模型、初态、参考帧和仿真设置，然后写出 `comparison.json`。用同一个 `report` 子命令汇总新结果：

```bash
python3 tools/evaluate_oldschool_exp020.py report \
  --results outputs/evaluation/exp020_replay/comparison.json
```
